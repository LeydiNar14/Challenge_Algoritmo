# Desafío 03 · Listas enlazadas

Proyecto básico de React + Vite, solo frontend y sin estilos.

## Cómo correrlo

```
npm install
npm run dev
```

Abre la dirección que muestra la terminal (normalmente http://localhost:5173).

## Qué incluye

- Clase `LinkedList` (lista simple): página "Reproductor", que avanza canción por
  canción con `next`.
- Clase `DoublyLinkedList` (lista doble): página "Historial", que va atrás y adelante
  con `prev` y `next`.
- Las dos listas se llenan con datos simulados.

Toda la lógica está en `src/App.jsx`.
